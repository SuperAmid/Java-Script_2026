# Лабораторная работа 1: Верстка калькулятора на HTML/CSS

## Цель работы
Знакомство с инструментами построения пользовательских интерфейсов web-сайтов: HTML, CSS.

## Задание
Создание калькулятора. Верстка на HTML, CSS.

## Выполненные задачи:
1. Создана HTML-разметка калькулятора
2. Реализована стилизация с помощью CSS
3. Выполнено индивидуальное задание: скопирована стилистика веб-ресурса **EA Sports** для калькулятора

## Индивидуальное задание:
Скопировать для калькулятора стилистику веб-ресурса [EA Sports | Официальный сайт](https://www.ea.com/ru-ru/sports)

### Выполнение:
- **Изменена цветовая палитра:** добавлен тёмный фон с неоновыми акцентами (синий, бирюзовый, оранжевый), характерный для динамичного стиля EA Sports. Реализован **синий бегущий верхний футер** (анимированная строка с градиентом) в духе спортивных трансляций.
- **Добавлены конкретные элементы стиля:** плавные hover-эффекты с масштабированием кнопок, стеклянная панель (glassmorphism), тени, адаптивная сетка, анимированная бегущая строка с информацией о функционале.
- **Адаптирована структура кнопок под стиль выбранного сайта:** добавлены кнопки математических функций (факториал `n!`, степень `xʸ`, квадратный корень `√x`, модуль `|x|`), а также кнопка расчёта стоимости услуги (`цена × кол-во`). 

## Контрольные вопросы:
1. **Основные составляющие web:** HTML (структура), CSS (стили), JavaScript (поведение), HTTP/HTTPS (протокол передачи), браузер (отображение), сервер (хранение данных).
2. **Описание URI:** URI (Uniform Resource Identifier) — унифицированный идентификатор ресурса. Пример для локального проекта: `file:///C:/PSP/JavaScript/index.html`. URI включает схему (file, http), имя хоста и путь.
3. **HTML для страницы из заголовка и абзаца текста:**
