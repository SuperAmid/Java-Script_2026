## Индивидуальное задание:
Добавление в калькулятор индивидуальной операции: **Расчет стоимости ПО**

### Операция:
`стоимость = базовая_цена × количество_лицензий × количество_пользователей`

### Реализация в коде:
```javascript
function calculateSoftwareCost(basePrice, licenseCount, userCount) {
    return basePrice * licenseCount * userCount;
}
