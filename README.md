# Лабораторная работа 1: Верстка калькулятора на HTML/CSS

## Цель работы
Знакомство с инструментами построения пользовательских интерфейсов web-сайтов: HTML, CSS.

## Задание
Создание калькулятора. Верстка на HTML, CSS.

2. Реализована стилизация с помощью CSS
3. Выполнено индивидуальное задание: скопирована стилистика веб-ресурса [укажите название сайта] для калькулятора
