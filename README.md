# Лабораторная работа 2: Логика калькулятора на JavaScript

## Цель работы
Знакомство с инструментами построения пользовательских интерфейсов web-сайтов: JavaScript.

## Задание
Создание калькулятора. Функции на JavaScript.

## Порядок показа:
1. Показать и объяснить индивидуальную операцию "Расчет стоимости ПО"
2. Объяснить, как связана кнопка `=` с кодом программы
3. Показать по этапам, как происходит сложение двух чисел в программе

## Выполненные задачи:
1. Реализована базовая логика калькулятора
2. Добавлены обработчики событий для всех кнопок
3. Реализована работа операций: +, -, ×, ÷
4. Добавлена индивидуальная операция: Расчет стоимости ПО
